# Kiểm thử tính năng ảnh — 18/11/2026

## Phạm vi và môi trường

Backend kiểm thử trong Docker project `khang-images-qa`, gateway cổng 8180, database riêng. Production smoke dùng project tạm và cổng 8186. Giao diện chụp trên Android Emulator `Small_Phone` 720 × 1280 với dữ liệu giả. Máy chủ demo cổng 8080 được sao lưu trước khi áp dụng migration bổ sung.

## Kết quả đã xác minh

| Nhóm | Kết quả |
| --- | --- |
| Avatar bốn vai trò | Tạo, đọc, thay, phiên bản ETag thay đổi, xóa lặp an toàn |
| Phân quyền avatar | Chặn ghi ảnh người khác, quyền đọc theo quyền hồ sơ |
| Ảnh bốn loại gói | Quản trị viên ghi, vai trò khác chỉ đọc, loại gói sai trả 404 |
| Ảnh lớp | Quyền đọc theo lớp, chỉ quản trị viên được ghi, xóa và tải lại đạt |
| Kiểm tra tệp | Chặn tệp giả ảnh, tệp vượt 5 MiB, kích thước giải mã vượt 24 triệu pixel |
| Thu hồi phiên | Phiên đã đăng xuất đọc ảnh trả 401 |
| Android | Chọn ảnh, xem trước và lưu avatar thành công trên ADMIN, RECEPTION, TRAINER, LEARNER |
| Hồi quy | Bộ `acceptance.mjs` đạt, có kiểm sinh lịch định kỳ và phục hồi Check-in |
| Production smoke | Bootstrap, migration, quyền database runtime và retention đạt |
| Sao lưu/khôi phục ảnh | Dump và restore ba database QA, đối chiếu số bản ghi và checksum nội dung ba bảng ảnh trùng nhau |
| HTTPS sau triển khai | Hai relay Internet trả health UP, đăng nhập, endpoint ảnh và đăng xuất đạt |
| Build Android 0.1.2 | Hai APK build đạt, lint 0 lỗi và 11 cảnh báo |

Android lint và Gradle còn cảnh báo hiện hữu của dự án, chưa thể xem là bản build không có cảnh báo. Chưa chạy lại SonarQube cho thay đổi ảnh này.

## Bằng chứng và cách chạy lại

- [30 ảnh giao diện chia theo vai trò](UI_GALLERY.md).
- [Kiểm thử API ảnh](../tests/images.mjs), tự tạo dữ liệu riêng trên stack QA, không cho chạy cổng 8080.
- [Script chụp emulator](../tests/capture-android.ps1), chỉ chấp nhận emulator. Dùng fixture tài khoản ở thư mục build đã được Git bỏ qua.
- CI chạy acceptance, kiểm thử ảnh, production smoke và Android build/lint.

```powershell
$env:MUAYTHAI_TEST_URL = 'http://127.0.0.1:8180'
node tests/images.mjs
```

Khi cần chụp lại, đặt `MUAYTHAI_IMAGE_FIXTURE_OUT` tới tệp JSON trong `android/app/build/`, chạy kiểm thử để tạo fixture. Đặt ảnh minh họa `course.jpg` cạnh fixture rồi chạy `tests/capture-android.ps1 -FixturePath <fixture> -ApkPath <APK trỏ QA>`. Fixture chứa thông tin đăng nhập thử, không đưa lên GitHub.

## Giới hạn nghiệm thu

Chưa xác minh chọn ảnh và quét QR bằng camera trên điện thoại thật, đồng bộ ảnh trên nhiều thiết bị, mất mạng khi tải ảnh hoặc khôi phục tiến trình Android trong lúc chọn ảnh. Bộ chụp ghi nhận các màn hình chính, không chứng minh toàn bộ 59 yêu cầu đã hoàn tất. Hai mốc nghiệm thu còn mở giữ nguyên trong [tiến độ](../PROGRESS.md).
